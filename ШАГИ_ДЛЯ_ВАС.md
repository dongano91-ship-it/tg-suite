## ШАГ 1: Подключить Railway к GitHub (2 минуты)

### 1.1 Откройте Railway
- Перейдите на **https://railway.app**
- Войдите через GitHub (кнопка "Log in with GitHub")

### 1.2 Если не видите проекты
Это значит, что Railway **не имеет доступа к вашим репозиториям**.

**Решение:**
1. В правом верхнем углу нажмите на вашу аватарку
2. Выберите **Account Settings** (Настройки аккаунта)
3. Перейдите в раздел **Integrations** (Интеграции)
4. Найдите **GitHub** и нажмите кнопку **"Connect"** или **"Configure"**
5. На открывшейся странице GitHub:
   - Выберите ваш аккаунт (**dongano91-ship-it**)
   - Выберите **"All repositories"** (Все репозитории)
   - Нажмите **"Install & Authorize"**
6. Вернитесь на Railway — теперь должны появиться 3 проекта!

## ШАГ 2: Создать 3 Telegram бота (5 минут)

### Для каждого бота:

1. Откройте Telegram, найдите **@BotFather**
2. Напишите `/newbot`
3. Придумайте имя (например: "Truck Watch Bot")
4. Придумайте username (например: `truck_watch_bot_001`) — должен заканчиваться на `bot`
5. **Скопируйте токен** (выглядит как `123456789:AAH...`)
6. Повторите для остальных двух ботов

### Получите chat_id получателей:

```powershell
cd C:\Users\donga\OneDrive\Documents\deepseek-harness\default-workspace
python get_chat_id.py <Ваш_Токен>
```

Попросите каждого из 4 человек написать боту любое сообщение. После этого скрипт покажет их ID.

Запишите все chat_id — они нужны для环境变量.

## ШАГ 3: Задеплоить на Railway (по очереди)

### Проект 1: Truck Watch

1. На Railway нажмите **New Project** → **Deploy from GitHub repo**
2. Выберите **truck-watch**
3. Нажмите **Settings** (настройки проекта)
4. Перейдите в **Variables**
5. Добавьте переменные:

| Variable | Значение |
|----------|----------|
| `TGW_TELEGRAM_TOKEN` | Токен первого бота от BotFather |
| `TGW_TELEGRAM_CHAT_IDS` | ID 4 людей через запятую (123456,789012,345678,901234) |
| `TGW_SHEET_URL` | `https://docs.google.com/spreadsheets/d/1GLkYhAZ094VIat3n2owKhvzykTAyPqqDDAeT5hdl1Fs/edit` |

6. Нажмите **Deploy**

### Проект 2: DealWatch

То же самое, выберите **dealwatch**, добавьте:

| Variable | Значение |
|----------|----------|
| `BOT_TOKEN` | Токен второго бота |
| `BOT_CHAT_IDS` | Ваш chat_id (или список) |

⚠️ **Важно:** DealWatch требует Chrome браузер. На Railway это может не заработать. Рассмотрите локальный запуск.

### Проект 3: TG Suite (FreeLLM Bot)

Выберите **tg-suite**, добавьте:

| Variable | Значение |
|----------|----------|
| `FREE_LLM_BOT_TOKEN` | Токен третьего бота |
| `FREE_LLM_API_URL` | `http://localhost:8080` |
| `ADMIN_CHAT_IDS` | Ваш chat_id |
