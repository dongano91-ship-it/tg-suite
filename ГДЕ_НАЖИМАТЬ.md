# 🎯 Куда именно нажимать — Пошаговая инструкция

## Шаг 1: Откройте Railway
- Перейдите: **https://railway.app**

---

## Шаг 2: Войдите через GitHub
- В правом верхнем углу нажмите кнопку **"Log in with GitHub"**

---

## Шаг 3: Если пишется "No projects found"

### Подключаем GitHub:
1. Кликните на вашу **аватарку** (справа вверху)
2. Выберите **Account Settings**
3. В меню слева найдите **Integrations**
4. Найдите блок **GitHub** → нажмите **Connect**

### На открывшейся странице GitHub:
1. Выберите аккаунт **dongano91-ship-it**
2. Поставьте галочку **"All repositories"**
3. Нажмите зеленую кнопку **"Install & Authorize"**

Вернитесь на Railway — нажмите F5 для обновления. Теперь должны появиться проекты!

---

## Шаг 4: Создайте проект Truck Watch

1. Нажмите **"+ New Project"**
2. Выберите **"Deploy from GitHub repo"**
3. В поиске наберите **truck-watch** → кликните по нему

---

## Шаг 5: Добавьте переменные (СЮДА ВВОДИМ!)

Когда откроется страница проекта:

1. В левом меню нажмите **Variables**
2. Нажмите **"+ Add Variable"**
3. В поле **Variable name** введите: `TGW_TELEGRAM_TOKEN`
4. В поле **Value** введите ваш токен от бота
5. Нажмите **"+ Add Variable"** еще раз для следующей переменной

### Переменные для truck-watch:

| Variable Name | Value |
|---------------|-------|
| TGW_TELEGRAM_TOKEN | ваш_токен_бота |
| TGW_SHEET_URL | https://docs.google.com/spreadsheets/d/1GLkYhAZ094VIat3n2owKhvzykTAyPqqDDAeT5hdl1Fs/edit |
| TGW_PLATES | 629,718,715,058,124 |

---

## Где взять токен?

1. Откройте Telegram
2. Найдите **@BotFather**
3. Напишите `/newbot`
4. Придумайте имя и username (оканчивается на bot)
5. BotFather пришлет токен вида: `123456789:AAH...`
6. Скопируйте его

---

## Шаг 6: Deploy!

После добавления переменных:
1. Нажмите кнопку **Deploy** (справа вверху)
2. Подождите 1-2 минуты
3. Проверьте логи во вкладке **Logs**

---

## Если ошибка "token invalid"

Это значит неверный токен. Создайте нового бота через @BotFather:
```
/newbot
```
Используйте новый токен.

---

## Если ошибка "chat not found"

Каждый получатель должен сначала написать боту любое сообщение!
