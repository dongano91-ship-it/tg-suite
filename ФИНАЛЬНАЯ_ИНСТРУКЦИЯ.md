## ШАГ 2: Задеплоить на Railway

### 2.1: Подключите GitHub к Railway

1. Откройте https://railway.app
2. Нажмите **"Login with GitHub"** (справа вверху)
3. Если видите свои проекты — переходите к Шагу 2.2
4. Если пишется "No projects found":
   - Кликните на аватарку → **Account Settings**
   - Выберите **Integrations** → найдите **GitHub** → нажмите **Connect**
   - На странице GitHub выберите аккаунт `dongano91-ship-it`
   - Поставьте галочку **"All repositories"**
   - Нажмите **"Install & Authorize"**
   - Вернитесь на Railway, обновите страницу (F5)

### 2.2: Создайте проект Truck Watch

1. Нажмите **+ New Project** → **Deploy from GitHub repo**
2. Выберите **truck-watch**
3. В левом меню нажмите **Variables**
4. Добавьте переменные:

| Variable Name | Value |
|---------------|-------|
| `TGW_TELEGRAM_TOKEN` | Токен вашего Truck Watch бота |
| `TGW_SHEET_URL` | `https://docs.google.com/spreadsheets/d/1GLkYhAZ094VIat3n2owKhvzykTAyPqqDDAeT5hdl1Fs/edit` |
| `TGW_PLATES` | `629,718,715,058,124` |

5. Нажмите кнопку **Deploy** (справа вверху)
6. Следите за логами — должно появиться:
   ```
   INFO:apscheduler.scheduler:Scheduler started
   INFO:bot:Бот запущен!
   ```

### 2.3: Создайте проект DealWatch

1. Нажмите **+ New Project** → **Deploy from GitHub repo**
2. Выберите **dealwatch**
3. В левом меню нажмите **Variables**
4. Добавьте переменные:

| Variable Name | Value |
|---------------|-------|
| `BOT_TOKEN` | Токен вашего DealWatch бота |
| `BOT_CHAT_IDS` | Ваш chat_id |

5. Нажмите кнопку **Deploy**
6. Следите за логами — при первом запуске может потребоваться пройти проверку CAPTCHA на Wildberries/Ozon вручную в браузере (это нормально)

### 2.4: Создайте проект TG Suite (FreeLLM Bot)

1. Нажмите **+ New Project** → **Deploy from GitHub repo**
2. Выберите **tg-suite**
3. В левом меню нажмите **Variables**
4. Добавьте переменные:

| Variable Name | Value |
|---------------|-------|
| `BOT_TOKEN` | Токен вашего FreeLLM бота |
| `FREE_LLM_API_URL` | `http://localhost:8080` |

⚠️ **Важно:** FreeLLM Bot требует, чтобы FreeLLM Desktop был запущен на вашем компьютере. Для удалённого доступа используйте ngrok:

```powershell
# Установите ngrok (если нет)
winget install ngrok.ngrok

# Запустите туннель в отдельном окне
ngrok http 8080

# Скопируйте https://xxxx.ngrok.io адрес и обновите переменную:
# FREE_LLM_API_URL=https://xxxx.ngrok.io/v1
```

5. Нажмите кнопку **Deploy**

## ❓ Устранение неполадок

### Ошибка "InvalidToken"
→ Не добавлена переменная `BOT_TOKEN` или неверный токен. Проверьте в Variables.

### Ошибка "ModuleNotFoundError"
→ Файл `requirements.txt` содержит BOM. Убедитесь, что он сохранён без BOM (UTF-8 без BOM).

### Ошибка "Chrome not found" (DealWatch)
→ DealWatch требует Chrome. Используйте Dockerfile, который я создал, или запускайте локально.

### Ошибка "Connection refused" (FreeLLM Bot)
→ FreeLLM Desktop не запущен. Запустите его или настройте ngrok.
