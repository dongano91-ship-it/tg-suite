# 🚀 TG Suite - Telegram Bots Collection

Три телеграм-бота для разных задач:

1. **Truck Watch** — мониторинг логистики из Google Таблицы
2. **DealWatch** — поиск выгодных предложений на маркетплейсах  
3. **FreeLLM Bot** — интерфейс к AI через FreeLLM API
