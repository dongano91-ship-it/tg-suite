🚀 Railway Deployment Guide

✅ Все репозитории готовы на GitHub:
• truck-watch
• dealwatch
• tg-suite

1 Откройте Railway

Перейдите по ссылке:

https://railway.app

Нажмите кнопку Login with GitHub (справа вверху)

2 Подключите GitHub

Если видите ваши проекты — переходите к Шагу 3

Если пишется "No projects found" или пусто:

  1. Кликните на вашу аватарку в правом верхнем углу
  2. Выберите Account Settings
  3. В меню слева найдите раздел Integrations
  4. Найдите карточку GitHub
  5. Нажмите кнопку Connect или Configure
⚠️ Далее откроется страница GitHub!
На ней нужно:
  1. Выбрать аккаунт dongano91-ship-it
  2. Поставить галочку "All repositories" (или выбрать вручную 3 репозитория)
  3. Нажать зеленую кнопку "Install & Authorize"

После этого вернитесь на Railway — обновите страницу (F5).

3 Создайте первый проект

На главной странице Railway нажмите кнопку + New Project

Выберите Deploy from GitHub repo

В поиске наберите truck-watch и выберите его из списка

📍 Сюда мы будем добавлять переменные позже

4 Добавьте переменные окружения

Когда проект загрузится:

  1. В левом меню нажмите Variables
  2. Нажмите кнопку + Add Variable

Для проекта truck-watch добавьте:

Имя переменной Значение
TGW_TELEGRAM_TOKEN Токен вашего бота от BotFather
TGW_TELEGRAM_CHAT_IDS ID получателей через запятую (например: 123456,789012,345678,901234)
TGW_SHEET_URL https://docs.google.com/spreadsheets/d/1GLkYhAZ094VIat3n2owKhvzykTAyPqqDDAeT5hdl1Fs/edit

Каждую переменную добавляйте отдельно, нажимая "+ Add Variable"

5 Повторите для других проектов

Проект dealwatch:

Имя Значение
BOT_TOKEN Токен второго бота
BOT_CHAT_IDS Ваш chat_id

Проект tg-suite:

Имя Значение
FREE_LLM_BOT_TOKEN Токен третьего бота
FREE_LLM_API_URL http://localhost:8080
ADMIN_CHAT_IDS Ваш chat_id

6 Как получить токены и ID

Токен бота (от BotFather):

  1. Откройте Telegram
  2. Найдите @BotFather
  3. Напишите /newbot
  4. Придумайте имя бота
  5. Придумайте username (должен оканчиваться на bot, например: my_truck_bot)
  6. Скопируйте токен (выглядит как 123456789:AAH...)

Chat ID получателей:

# Запустите в PowerShell:
cd C:\Users\donga\OneDrive\Documents\deepseek-harness\default-workspace
python get_chat_id.py <ВАШ_ТОКЕН>

# Затем попросите каждого человека написать боту любое сообщение.
# Скрипт покажет их ID.

7 Deploy!

После добавления всех переменных:

  1. Нажмите кнопку Deploy (обычно справа вверху)
  2. Подождите 1-2 минуты
  3. Перейдите во вкладку Logs чтобы видеть процесс
✅ Когда увидите зелёную галочку — бот запущен!

❓ Если возникают ошибки

Ошибка Что делать
"No projects found" Повторите Шаг 2 (подключение GitHub)
"Token invalid" / 401 Создайте нового бота в @BotFather и скопируйте токен заново
"chat not found" / 400 Убедитесь, что человек написал боту первое сообщение
Build failed Проверьте логи во вкладке Logs

После выполнения этих шагов напишите мне — помогу проверить работу ботов!
