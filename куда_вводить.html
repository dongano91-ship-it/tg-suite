🎯 Куда именно нажимать на Railway

Шаг 1: Откройте Railway

Перейдите по адресу:

https://railway.app
⬇️

Шаг 2: Вход через GitHub

В правом верхнем углу нажмите кнопку:

Login with GitHub

(или "Sign In" → затем выберите GitHub)

⬇️

Шаг 3: Если видите "No projects found"

Это значит нужно подключить GitHub:

  1. Кликните на вашу аватарку (справа вверху)
  2. Выберите Account Settings
  3. В меню слева найдите Integrations
  4. Найдите блок GitHub
  5. Нажмите кнопку Connect

Далее откроется страница GitHub — там нужно:

  • Выбрать аккаунт dongano91-ship-it
  • Поставить галочку "All repositories"
  • Нажать зеленую кнопку Install & Authorize
⬇️

Шаг 4: Создать проект

Когда появится список проектов, нажмите кнопку:

+ New Project

Затем выберите:

Deploy from GitHub repo
⬇️

Шаг 5: Выбрать репозиторий

В поиске наберите название проекта и кликните по нему:

Бот Что искать в списке
Truck Watch truck-watch
DealWatch dealwatch
FreeLLM Bot tg-suite
⬇️

Шаг 6: Добавить переменные (ВАЖНО!)

Когда проект загрузится, в левом меню нажмите:

Variables

Затем нажмите кнопку:

+ Add Variable

Для truck-watch введите:

Variable Value
TGW_TELEGRAM_TOKEN Ваш токен от @BotFather (когда создавали бота)
TGW_SHEET_URL https://docs.google.com/spreadsheets/d/1GLkYhAZ094VIat3n2owKhvzykTAyPqqDDAeT5hdl1Fs/edit
TGW_PLATES 629,718,715,058,124

Каждую строку добавляйте отдельно!

⬇️

Где взять токен бота?

В Telegram найдите @BotFather, напишите ему:

/newbot

Придумайте имя (например: TruckWatchBot)

Придумайте username (должен оканчиваться на bot, например: my_truck_bot_123)

Скопируйте полученный токен (выглядит как: 123456789:AAHxyz...)

Вставьте его в поле TGW_TELEGRAM_TOKEN на Railway.

Как получить chat_id получателей?

Запустите в PowerShell:

cd C:\Users\donga\OneDrive\Documents\deepseek-harness\default-workspace
python get_chat_id.py ВАШ_ТОКЕН

Попросите каждого из 4 человек написать боту сообщение.

После этого скрипт покажет их ID — скопируйте их.

⬇️

Шаг 7: Deploy!

После добавления всех переменных нажмите кнопку:

Deploy

Подождите 1-2 минуты. Внизу появится вкладка Logs — там видно что происходит.

Если возникают ошибки — опишите что пишется на экране, помогу!
